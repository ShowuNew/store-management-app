# 各角色功能目錄

> 最後更新：2026-06-05

---

## 角色列表

| 角色代碼 | 中文名稱 | 登入方式 | 登入後首頁 |
|---------|---------|---------|-----------|
| `staff` | 店員 | 登入頁 | `dashboard` |
| `manager` | 店長 | 登入頁 | `dashboard` |
| `sub-manager` | 小店長 | `?sub-token=xxx` URL（無需登入） | `dashboard` |
| `supervisor` | 擔當 | 登入頁 | `admin-dashboard` |
| `admin` | 系統管理員 | 登入頁 | `admin-dashboard` |

---

## 店員（staff）

登入後進入員工首頁，僅能操作**當日**、**自己門市**的資料。

| 功能 | 頁面 | 說明 |
|------|------|------|
| 首頁 | `dashboard` | 今日工作概覽 |
| 每日工作確認 | `daily-work` | 溫度記錄、廢棄物確認、機器清潔時間、友善食光、交接班紀錄 |
| 衛生自主管理 | `hygiene` | 衛生自主檢查項目填寫 |
| 設備清潔保養 | `equipment` | 勾選設備保養完成項目 |
| 咖啡自檢 | `coffee-check` | 咖啡機自我檢查 |
| C15 確認 | `c15-check` | C15 表單填寫 |
| 店鋪點檢表 | `inspection` | 店鋪點檢項目填寫 |
| 異常回報 | `anomaly` | 建立異常事項 |

---

## 店長（manager）

繼承店員全部功能，另加以下權限：

| 功能 | 頁面 | 說明 |
|------|------|------|
| 紀錄查閱 | `admin-records` | 查閱自己門市的歷史填報紀錄 |
| 小店長連結建立 | `sub-manager-manage` | 產生臨時小店長填報連結，可設定有效期間 |
| 日期補填 | 各填報頁面 | 可選擇歷史日期補填各項紀錄 |
| 班次填寫狀況 | 首頁 | 顯示今日早班／晚班／大夜班填寫進度 |
| 異常自動彈窗 | 首頁 | 登入時自動顯示當日未處理異常事項 |
| 標記「無此設備」 | 每日工作確認、設備保養 | 可將不適用的機器標記為無此設備 |
| 自訂溫度項目 | 每日工作確認 | 可新增額外溫度量測設備 |
| 多門市切換 | 全域 | 若管理多間門市，可切換目前操作門市 |

---

## 小店長（sub-manager）

與店長功能幾乎相同，以下為差異：

| 差異項目 | 說明 |
|---------|------|
| ❌ 小店長連結建立 | 無法產生新連結，需由店長建立後透過 `?sub-token=xxx` 進入 |
| 其餘功能 | 與店長相同 |

---

## 擔當（supervisor）／系統管理員（admin）

登入後直接進入**後台管理介面**，管理範圍涵蓋全部門市。

| 功能 | 頁面 | 說明 |
|------|------|------|
| 後台總覽 | `admin-dashboard` | 全門市填報狀況總覽 |
| 店鋪狀況 | `admin-store-status` | 各門市完成進度一覽 |
| 紀錄查閱（全門市） | `admin-records` | 跨門市查閱所有填報紀錄 |
| 異常管理 | `admin-anomaly` | 管理全門市異常事項 |
| 數據統計 | `admin-stats` | 全門市統計報表 |
| 神秘客管理 | `mystery-manage` | 建立／管理神秘客稽查連結 |
| 每日填報查核 | `admin-fill-check` | 各門市缺填狀況統計 |
| 功能點擊排行 | `admin-feature-clicks` | 各功能使用頻率統計 |

## 特殊公開入口（無需登入）

| URL 參數 | 功能 | 適用對象 |
|---------|------|---------|
| `?token=xxx` | 神秘客稽查表單 | 店外稽查人員填寫 |
| `?sub-token=xxx` | 小店長工作日誌 | 店長授權的臨時帳號 |
